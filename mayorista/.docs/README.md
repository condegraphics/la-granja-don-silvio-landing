# La Granja Don Silvio Mayorista

Lista de precios interactiva. Los clientes eligen productos y cantidades, revisan el total estimado y envían el pedido a ventas por WhatsApp.

## Desarrollo local

El sitio es HTML, CSS y JavaScript nativo, sin dependencias de compilación. Desde la raíz del proyecto, iniciá un servidor local:

```sh
python -m http.server 8000
```

Abrí `http://localhost:8000`.

## Publicación

El workflow de GitHub Actions publica el contenido estático desde `main` en GitHub Pages.
