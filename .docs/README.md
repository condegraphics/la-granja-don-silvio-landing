# La Granja Don Silvio — Landing

Landing institucional y comercial mobile-first construida con HTML5 semántico y CSS3 puro, sin JavaScript funcional propio.

## Estado actual

**v0 visual / cambio preparado, no publicado en producción.** Incluye estructura de conversión, SEO base, Schema.org, CTAs `tel:` y WhatsApp segmentados, ofertas, sucursales y carpeta `img/` para activos oficiales.

## Fuente de datos

Los datos comerciales, teléfonos, WhatsApp, ofertas, direcciones y horarios provienen exclusivamente de `granja-don-silvio-2026.md`, compartido en el proyecto Manus.

## Desarrollo local

Abrir `index.html` en un navegador. No requiere instalación, compilación ni dependencias.
