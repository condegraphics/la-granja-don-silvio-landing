# Activos visuales pendientes

Esta carpeta está reservada para los activos oficiales aprobados de La Granja Don Silvio:

- `logo.svg` o `logo.png`
- `logo-light.svg` o `logo-light.png` si existe una variante para fondos oscuros
- Fotos reales de productos, sucursales y equipo, preferentemente en WebP/AVIF

No se incorporaron imágenes inventadas ni de stock porque la documentación del proyecto no contiene activos visuales. Al recibirlos, actualizar el `brand-spec.md` y reemplazar los marcadores `[logo]` y `[foto de productos pendiente]` del v0.
